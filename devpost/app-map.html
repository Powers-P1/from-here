FROM HERE / reference guide

One notice. One checked sign.

A photo becomes a clearer A3 sign. Its author confirms the facts; local AI plans the layout and reads the actual result. The same checked artwork becomes the PDF.

This is a reference route through the implementation, not a claim that the participant completed a guided tour.

Follow “Confirm & redesign”

Confirm facts→Plan · render · fresh read→Checked SVG / A3 PDF
  1. Keep the author's version.
    src/workflow/useWorkflow.ts → saveFacts / act

    The interface saves edited facts and sends their version when design starts. server/jobs.ts → updateFacts invalidates the previous preview and report, so an old pass cannot approve a changed notice.

  2. Make and inspect a real sign.
    server/agent/pipeline.ts → designAndCheck

    The agent gets a bounded layout plan, calls the renderer and reads the resulting PNG. server/agent/prompts.ts → readSign receives only that image; its fresh parser sees only the new transcription. Neither step receives the original or expected answers. Two repairs is the maximum, not a required animation.

  3. Export the checked artwork.
    server/api.ts → GET /jobs/:id/download

    The API checks the report and artifact hash before allowing a final export. server/render/renderer.ts → exportPdf uses the same SVG, waits for fonts and creates one exact 297 × 420 mm page. A stopped result can only offer an explicitly unchecked SVG draft.

A practice to reuse

Define the failure before calling a result “checked”. An early comparison treated “Grades 1–2” like “Grades 12”. tests/contracts.test.ts now rejects that difference and keeps entire time/date ranges. The acceptance criterion in devpost/prd.md → Confirm facts and conditions has an observable test. For another project, choose one small example where a plausible-looking answer would still be wrong.

What the evidence does and does not establish

The kernel proof uses actual local inference, generated artwork and a reopened PDF. Browser regression tests use explicitly mocked API responses, so they test interactions and recovery. Neither is a human reading-distance or accessibility certification. Personal learning reflections and survey answers are not supplied by the agent.

Main pieces and temporary storage

React renders the interface. Express holds transient jobs in memory; jobs more than 60 minutes old are removed when idle. Ollama Qwen3-VL transcribes images; local vLLM Gemma parses facts and plans layouts. Chromium measures actual fonts, rasterizes and prints. Restarting the app clears jobs. No account, database or cloud API key is part of this build.
